# ScupSchool page templates

This directory contains reference templates for recurring ScupSchool page types.

These files are not rendered as learner-facing webpages.

## Available templates

- `core-learning-page.qmd` — required individual learning material
- `cycle-overview.qmd` — introduction to one meeting-centred learning cycle
- `meeting-readiness.qmd` — individual preparation checklist
- `meeting-page.qmd` — guidance for an in-person team meeting
- `module-closing.qmd` — team-level module submission checkpoint
- `support-page.qmd` — optional situation-based support material

## How to create a new page

1. Copy the relevant template.
2. Paste the copy into the appropriate learning-cycle or support folder.
3. Rename the copied file using a short ASCII filename.
4. Replace the placeholder YAML values.
5. Replace all instructional placeholder text.
6. Add the new page to the appropriate navigation order.
7. Preview the website and test all links.

## Important rule

After copying a template, edit the new page directly.

Do not edit the template to change one existing course page.
